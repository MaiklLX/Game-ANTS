## Changes

- Added `ResponsiveLayout` to calculate a uniform scale, horizontal centering offset, virtual viewport size, and available extra portrait height.
- The gameplay screen now uses the full available portrait height instead of vertically letterboxing the 720×1280 canvas on common taller phones.
- Four-squad levels (including the level-100 finale) use compact 156 px cards with 8 px gaps, fitting all four within the 720 px design width while preserving a 48 px physical card height at the compact reference scale.
- Lower sections progressively consume extra height: deployment slots, squad cards, board, status panel, and level picker. This preserves the relative order and keeps the board's cell dimensions uniform.
- Increased the vertical hit areas for squad cards, tutorial Skip, level controls, and Retry. The compact level-number controls remain narrower than the 44 px width guideline and are explicitly identified as such in tests; this is a known follow-up to replace with a scrollable selector or wider compact layout.
- Pointer/touch conversion continues to use the exact inverse of the draw transform.
